# Outreach

Ready-to-post drafts for sharing the book, and a log of what was actually posted.

## How it works

1. **Drafts.** Every verified page gets a file in [`posts/`](posts/) with a draft for each channel: LinkedIn, X, dev.to / Hashnode, Reddit and Hacker News.
2. **Pick and post.** When there is time, the maintainer picks one draft, edits it in their own voice, and posts it.
3. **Log.** The maintainer tells the agent what was posted, where, and the link. The agent records it in [`LOG.md`](LOG.md) and marks the draft as posted.
4. **Measure.** Once a month, the agent adds the numbers that are visible without logging in (reactions, comments, stars, Search Console clicks the maintainer shares) to the log.

## Rules for drafts

* Same standards as the book: every claim in a post must also be on the page it links to, with its source. No invented numbers, no hype words, no em dashes.
* Be upfront that the first draft was AI-assisted and is verified in the open. That honesty is part of the pitch, not something to hide.
* Lead with something useful (a finding, a mistake, a checklist item), not with "I built".
* Link to the specific page, not just the home page.
* **Reddit and Hacker News:** read each community's self-promotion rules first, and post only when several pages are verified. Those audiences are harsh on unfinished work, and a bad first impression is hard to undo.
